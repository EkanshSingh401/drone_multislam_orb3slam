Tools: `gain_ladder` (C++, the planner's own `score_path` machinery, only the inputs change per rung),

scratch build of OpenVINS (`day5/ov_stage_logdet.patch`; pinned fork unchanged), run in deterministic
serial replays. Data: all 46 path-integrated pose_cov flights of days 3–4 (1506 flown goals; horizon
decision → arrival median 3.9 s, IQR 2.4–5.8 s) + the 2 day-4 sensor flights for replays.
Gate: rung `plan_real` reproduces the logged dI_prop + dI_meas_real (median |diff| 0, 78% within 0.01
nats, p95 0.17 — residual from which JC message the planner held).

The correlation does not collapse at a rung: it is weak at **every** rung, oracle included (≤ 0.24),
and every rung over-predicts by 1.8–3.5 nats. Giving the predictor the true path and the true feature
set does not fix it, so the problem is not the inputs (path, visibility, feature choice).

Where it does break — **horizon** (same deterministic replay, model from each JC snapshot vs the
realized stage log; d4_sens_lam0_1 / _2):

| horizon | model meas. gain | realized meas. gain | model net | realized net | Spearman (net) |
|---|---|---|---|---|---|
| 1 update cycle (~0.07 s) | 0.052 / 0.050 | 0.050 / 0.048 | — | — | 0.79 (flight 1) |
| 0.5 s | 0.51 / 0.46 | 0.36 / 0.34 | +0.19 / +0.14 | 0.00 / 0.00 | 0.27 / 0.22 |
| 1 s | 1.61 / 1.39 | 0.77 / 0.74 | +1.04 / +0.81 | 0.00 / 0.01 | 0.17 / 0.20 |
| 2 s | 3.64 / 3.37 | 1.55 / 1.46 | +2.46 / +2.21 | 0.00 / 0.01 | 0.26 / 0.21 |
| 5 s | 6.62 / 6.36 | 3.99 / 3.68 | +3.68 / +3.45 | +0.02 / +0.04 | 0.50 / 0.36 |

One step is right (meas. gain ratio 1.06, propagation 0.049 vs 0.052 nats; the §61–62 agreement),
and the model's propagation loss is close at every horizon (0.65 nats/s on the 1506 goals vs 0.67–0.70
realized). The model's *measurement* information from one snapshot grows ~2x faster than the filter's
from 0.5 s on. Realized, the pose covariance is at an equilibrium: per 5 s propagation removes
3.6–4.0 nats and updates put back the same amount (net +0.02–0.07).
Where the excess sits (2 s horizon): ~70% outside the local roll/pitch block, i.e. in yaw/position,
the directions a VIO filter cannot observe; roll/pitch itself is over-predicted 1.6x (1.65 vs 1.02
nats). The excess is largest when the vehicle **rotates with little translation** (1 s: model/realized
3.3 in the top rotation tertile vs 1.3 with no rotation; 3.5 in the lowest translation tertile vs 1.2
in the highest) — not a parallax effect. **FEJ is not the explanation**: replaying the same flight with
`use_fej: false` (diagnostic) leaves the filter's realized flows unchanged (net 0.044 vs 0.041 nats/s,
same split), so linearization-point differences do not create the extra information in the filter.
Remaining candidate (untested): the predictor propagates with a static, non-rotating IMU model
(synthetic level, unaccelerated) and maps clone errors to the waypoint attitude only inside the
measurement Jacobians; under rotation the real error dynamics (gyro-bias and gravity coupling in a
rotating frame) differ. Next test: predictor with the flown IMU propagation (sensor flights) instead of
the static model.

**b) Realized information by source** (stage log, airborne, two flights): SLAM-landmark updates
**89–90%**, MSCKF 9%, delayed SLAM init 1%; the median MSCKF update uses **1** feature (the 50 SLAM
slots take the long tracks). Per 5 s: propagation −3.6 to −4.0 nats, SLAM +3.3 to +3.5, MSCKF
+0.2 to +0.3, init ~0. Landmarks leaving the window cost the model little: persistent vs windowed
landmarks on the same path differ by 0.05 nats median (IQR 0.01–0.14). Marginalization changes the
pose marginal by exactly 0 (as it must).

**c) What carries signal for realized Δlogdet** (1506 goals; Spearman [95% CI over flights];
leave-one-flight-out R² of a single-feature linear fit):
visible GT surface in the FOV at arrival (emulated depth rays ≤ 8 m) ρ = 0.25 [0.21, 0.30], R² 0.01;
visible real landmarks (logged lm_vis) ρ = **−0.27** [−0.36, −0.18], R² 0.11; predicted gain
ρ = 0.16 [0.08, 0.24], R² 0.00; path length ρ = 0.03, rotation ρ = 0.04, horizon ρ = 0.06 (all ≈ 0).
All six together: R² 0.26 leave-one-flight-out (0.29 in sample), carried by path length and horizon
with large opposite coefficients (collinear) plus lm_vis. Realized changes at goal scale are small and
mostly equilibrium noise; nothing simple predicts them well, and the predicted gain least of all.
